# 💻 Server Performance Stats Script

A simple Bash script to analyze basic server performance metrics on any Linux system.

---

## 🚀 Features

This script provides:

- 🧠 Total CPU usage
- 💾 Total memory usage (Used / Free / Percentage)
- 💽 Total disk usage (Used / Free / Percentage)
- 🔥 Top 5 processes by CPU usage
- 🔥 Top 5 processes by Memory usage
- ⏳ System uptime
- 🖥️ Hostname & Date information

---

## 📦 Requirements

Make sure your system has:

- Linux OS (Ubuntu, Debian, etc.)
- Bash shell
- Standard Linux utilities:
  - `top`
  - `ps`
  - `df`
  - `awk`
  - `grep`

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/MehediHaassan1/Server-Performance-Stats.git
cd server-performance-stats
```

## ⚙️ Give Execute Permission

Before running the script, make it executable:

```bash
chmod +x server-stats.sh
```

## ▶️ How to Run

Run the script using:

```bash
./server-stats.sh
```

or

```bash
bash server-stats.sh
```
